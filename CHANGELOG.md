# Changelog

## 0.0.1 - 2026-10-21

Первый релиз. Бот по расписанию шлёт в группу факт про баню с картинкой и неанонимный опрос «Иду / Не иду», голоса пишет в SQLite.

### Добавлено

- Недельный ритуал по cron (по умолчанию вторник, 18:00, `Asia/Almaty`): факт, затем опрос. Второй опрос на ту же ISO-неделю не создаётся.
- Голоса сохраняются с именами. Снятый голос из журнала удаляется.
- Напоминание раз в час, если сутки никто не голосовал. Повтор на ту же неделю не отправляется.
- Картинка к факту с Wikimedia Commons. Если поиск ничего не нашёл, бот прикладывает запасное фото бани.
- Факты и текст напоминания через Gemini (`gemini-3.5-flash-lite`), если задан `GEMINI_API_KEY`. Уже отправленные формулировки в запрос не попадают. Без ключа или при ошибке бот берёт факт из `facts.json`.
- Команды `/help`, `/stats`, `/stats last`, `/banya`, `/fact` и `/start`. Через `/start` в личке админ задаёт расписание и группу; эти значения хранятся в SQLite и при старте перекрывают `CRON` и `BANYA_CHAT_ID`.
- Запуск через Docker Compose и systemd. Сборки `linux/amd64`, `linux/arm64` и `linux/armv7`. Образ в GHCR публикуется при push в `master`.
